# quá trình
- **Mã:** qua-trinh
- **Tên khác:** process; tập hợp hoạt động biến đầu vào thành đầu ra
- **Anh:** process
- **Ngắn:** Tập hợp các hoạt động có quan hệ lẫn nhau hoặc tương tác để biến đổi đầu vào thành đầu ra; trả lời câu hỏi WHAT.

## Định nghĩa
- Slide 05/11 (nguyên tắc 4) trích định nghĩa ISO 9000: quá trình là tập hợp các hoạt động có quan hệ lẫn nhau hoặc tương tác để biến đổi đầu vào thành đầu ra; hình so sánh ghi QUÁ TRÌNH (Process) = WHAT?, chuỗi hoạt động (activities, sub-process).
- Sơ đồ trên slide: INPUTS → Process → OUTPUTS.

## Ví dụ số
- Ví dụ giả định của bài: sản xuất nước ép gồm tiếp nhận, phối chế, rót chai là một quá trình; đầu vào là nguyên liệu, đầu ra là chai thành phẩm.
